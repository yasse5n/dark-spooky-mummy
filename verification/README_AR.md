# فحص المصدر وإعادة بناء الملفات المتوافقة

الكود والنتائج فقط؛ لا توجد صور عملاء أو لقطات متصفح ضمن الحزمة.

- ui.test.cjs: فحوص واجهة بالبيانات الوهمية؛ يحتاج Playwright ومتصفح Chromium ومسار مصدر السيرفر في QAYEM_SERVER_ROOT.
- integration.test.cjs: يشغل سيرفرًا محليًا بقاعدة بيانات مؤقتة ويجرب تسجيل الدخول والتفعيل السنوي ونشر كارت سوشيال وعرضه في البلاجن.
- استخدم QAYEM_PLAYWRIGHT_MODULE لمسار مكتبة Playwright وQAYEM_CHROME_PATH لمسار المتصفح إذا اختلفت البيئة.
- build-compat.cjs يعيد بناء الملفات الأربعة المعدلة فقط إلى compat، بهدف Chromium 41، ويتحقق من أن سكربتات compat الثمانية والسبعين تقبل صياغة ES5. يحتاج npm ci داخل هذا المجلد أولًا.
- إعادة البناء تعدّل ملفات المصدر مباشرة.
- لم تُجرَ تجربة فوتوشوب أصلية على Windows أو macOS لهذا الإصدار.
